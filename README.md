# Проект my_marketplace

## Описание:

Проект my_marketplace - это тестовое приложение для создания проекта интернет-магазина.

## Стек используемых технологий (библиотек):
+ Python 3.12.10
+ poetry
+ django 6.0.3
+ dotenv 0.9.9
+ psycopg-2-binary
+ dotenv
Все контроллеры имеют способ определения и обработки представлений в Django с помощью классов(метод CBV).

## Установка:

1. Клонируйте репозиторий:
    ```
     https://github.com/ViktorPilot/my_marketplace.git
    ```
2. Запустите PyCharm у себя на компьютере.
3. Откройте скачанный репозиторий в PyCharm.
4. Создайте виртуальное окружение командой `poetry install`.
5. Активируйте ВО командой `poetry env activate`.
6. Установите зависимости командой `poetry init`.
7. Программа готова к работе.

## Запуск локального сервера:

1. Для запуска локального сервера у себя на компьютере необходимо в терминале ввести команду:
`python manage.py runserver 8000`(для Windows), `python3 manage.py runserver 8000`(для Unix-систем), 
где крайним значением указан порт запускаемого сервера.

## Порядок работы со страницами браузера приложения `catalog`:

1. В браузере перейти на страницу с адресом `127.0.0.1:8000/home/`, которая является главной страницей приложения.
Для постраничного вывода списка товаров необходимо использовать пагинаторы `Вперед`, `Назад`. 
Для просмотра подробной информации о товаре нажать на кнопку `перейти` в карточке интересующего товара.
2. Для просмотра страницы `Контакты` необходимо выбрать вкладку `Контакты` или перейти 
по адресу: `127.0.0.1:8000/contacts/`.
3. В разделе `Свяжитесь с нами` ввести данные пользователя (Имя, телефон, сообщение) и нажать `Отправить`.
4. При успешном получении сообщения на сервере дождаться ответа о приеме данных. 
5. Для добавления товаров и категорий в базу данных необходимо перейти в админку по адресу `127.0.0.1:8000/admin/`, 
ввести учетные данные. После входа выбрать `add товар` или `add категория` заполнить поля информации, 
далее выбрать `save`.
6. Альтернативный способ заполнения базы данных товарами:
   + перейти по адресу `127.0.0.1:8000/add_product/` или выбрать вкладку `Добавить товар`. Заполнить поля информации 
о товаре, нажать `Добавить`.
   + при успешном добавлении товара в базу данных происходит переход на страницу с сообщением `Товар успешно добавлен!`. 
7. При переходе по адресу `127.0.0.1:8000/home/` дополнительно предусмотрен вывод в консоль 5 крайних 
добавленных товаров.
8. При переходе по адресу `127.0.0.1:8000/contacts/` дополнительно предусмотрено отображение на странице 
крайних добавленных трех контактов из базы данных.

## Порядок работы со страницами браузера приложения `blog`:

1. В браузере перейти на страницу с адресом `127.0.0.1:8000/blogs/`, которая является главной страницей приложения.
Для просмотра подробной записи блога нажать на кнопку `Перейти` в карточке интересующей записи.
Для добавления новой записи нажать на кнопку `Добавить запись`.
2. На странице создания новой записи заполнить поля формы и нажать кнопку `Сохранить`.
Для возврата в главное меню нажать на кнопку `Главное меню`.
3. На странице с подробной информацией о записи представлена информация о заголовке, содержимом, превью (изображении),
дате создания, признаке публикации (булевое поле), количестве просмотров.
Для редактирования существующей записи нажать на кнопку `Редактировать`.
Для удаления существующей записи нажать на кнопку `Удалить`.
Для возврата в главное меню нажать на кнопку `Главное меню`.
4. На странице редактирования существующей записи заполнить поля формы и нажать кнопку `Сохранить`.
Для возврата в главное меню нажать на кнопку `Главное меню`.
После сохранения записи происходит автоматический переход на страницу отредактированной записи.
5. На странице удаления существующей записи подтвердить удаление нажать на кнопку `Удалить`.
При отмене удаления существующей записи нажать на кнопку `Отменить`.
При этом происходит переход на страницу с текущей записью.
6. Предусмотрено увеличение счетчиков просмотра записей при переходе на страницу записи. 
При достижении количества просмотров статьи - 100, происходит отправка поздравительного сообщения на электронную почту.
7. На главную страницу происходит вывод только тех записей, которые имеют положительный признак публикации.
