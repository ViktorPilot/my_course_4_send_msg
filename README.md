# Проект my_course_4_send_msg

## Описание:

Проект my_course_4_send_msg - это сервис управления рассылками, администрирования и получения статистики.

## Стек используемых технологий (библиотек):
+ Python 3.12.10
+ poetry
+ django 6.0.4
+ dotenv 0.9.9
+ psycopg-2-binary 2.9.12
+ python-dotenv 1.2.2
+ redis 4.5.5
Все контроллеры имеют способ определения и обработки представлений в Django с помощью классов(метод CBV)
и функций(метод FBV).

## Установка:

1. Клонируйте репозиторий:
    ```
     https://github.com/ViktorPilot/my_course_4_send_msg.git
    ```
2. Запустите PyCharm у себя на компьютере.
3. Откройте скачанный репозиторий в PyCharm.
4. Создайте виртуальное окружение командой `poetry install`.
5. Активируйте ВО командой `poetry env activate`.
6. Установите зависимости командой `poetry init`.
7. Создайте и заполните файл `.env`.
8. Примените миграции `python manage.py migrate`.
9. Загрузите фикстуры из файла: 
`python -Xutf8 manage.py loaddata fixtures/service/service_sending.json`,
`python -Xutf8 manage.py loaddata fixtures/users/users.json`.
10. Скачайте установочный файл Redis для Windows с GitHub: https://github.com/microsoftarchive/redis/releases.
11. Распакуйте скачанный архив и запустите `redis-server.exe`.
12. Программа готова к работе.

## Запуск локального сервера:

1. Для запуска локального сервера у себя на компьютере необходимо в терминале ввести команду:
`python manage.py runserver 8000`(для Windows), `python3 manage.py runserver 8000`(для Unix-систем), 
где крайним значением указан порт запускаемого сервера.

## Порядок работы со страницами браузера приложений `service` и `users`:

1. Реализована возможность добавлять, просматривать получателей рассылки (клиентов) с помощью выпадающего
список на навигационной панели. Редактировать и удалять получателей рассылки (клиентов) возможно со страницы просмотра
детальной информации о клиенте.
2. Реализована возможность добавлять, просматривать сообщения с помощью выпадающего список на навигационной панели. 
Редактировать и удалять сообщения возможно со страницы просмотра детальной информации о сообщении.
3. Реализована возможность добавлять, просматривать рассылки с помощью выпадающего список на навигационной панели. 
Редактировать и удалять рассылки возможно со страницы просмотра детальной информации о рассылке.
4. Реализована возможность вручную запускать рассылку через интерфейс пользователя и командную строку. Для запуска 
рассылки через командную строку необходимо использовать команду `python manage.py send_messages --id 1`, 
где после --id указывается id рассылки.
5. Для каждой попытки отправки сообщения в БД сохраняется: дата и время попытки, статус, ответ почтового сервера,
внешний ключ на рассылку.
6. На главной странице приложения (навигационная панель: `HOME`) отображаются следующие показатели: 
общее количество всех созданных рассылок, количество активных рассылок, количество уникальных получателей.
7. Реализована система регистрации и аутентификации пользователей. Через навигационную панель, 
выпадающий список `Профиль`.
8. Пользователи имеют возможность зарегистрироваться на сайте, подтвердив свой email. При регистрации нового 
пользователя на указанный email приходит ссылка для авторизации пользователя. Необходимо перейти по данной ссылке, 
после чего ввести данные для входа в аккаунт.
9. Реализована функция входа и выхода из системы.(Навигационная панель, выпадающий список `Профиль`).
10. Предусмотрена возможность восстановления пароля. При неавторизованном пользователе, на странице входа в аккаунт
необходимо выбрать `Забыли пароль?`, после чего в открывшемся окне ввести свой email и нажать `Отправить ссылку`.
На указанный email приходит ссылка для восстановления пароля. Перейдя по ссылке, ввести новый пароль и подтвердить его
повторным вводом, после чего ввести данные для входа в аккаунт.
11. Собирается и отображается информацию о количестве успешных/неуспешных попыток рассылок пользователя 
и количестве отправленных сообщений. (Навигационная панель, вкладка `Статистика`).
12. Пользователи могут создавать, просматривать, редактировать и удалять своих клиентов и рассылки, а также
просматривать статистики по своим рассылкам.
13. Менеджеры могут просматривать всех клиентов и рассылок, просматривать список пользователей сервиса 
(Навигационная панель, `Список пользователей`), блокировать пользователей сервиса (на странице `Список пользователей`),
отключать рассылки (на странице списка рассылок). 
14. Настроено серверное (страницы информации о клиенте, информации о сообщении) и клиентское кеширование 
(страницы информации о попытках рассылок) для повышения производительности.
